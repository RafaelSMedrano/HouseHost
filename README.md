# HouseHost
Administre seu hotel


O HouseHost é um sistema pensado para gerir fluxo de hospedes e finanças
de um hotel.

Tecn:
backend spring boot front end javascript estático

O sistema inclui gerar um sitepara divugação, com cadastro e controle de hospedes
O site está, como exemplo em househost.com.br, a area de adm em househost.com.br/admin, as duas areas compartilhando o
mesmo backend e dados. pra entrar na area admin vai ser necessário login e senha.
