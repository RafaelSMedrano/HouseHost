Guia Visual do Objeto event

Um material prático para entender de onde vem o event, como ele aparece no seu registrationWidget e quando usar métodos como preventDefault(), stopPropagation(), target e currentTarget.

Para transformar em PDF: abra este HTML no navegador e use Imprimir > Salvar como PDF.

1. A Ideia Principal

O event é um objeto criado automaticamente pelo navegador quando alguma coisa acontece: clique, envio de formulário, digitação, movimento do mouse, carregamento da página e assim por diante.

Você não cria o event. O navegador cria e entrega para a função que você registrou. 

form.onsubmit = (event) => {
    // O navegador chama esta função quando o form é enviado.
    // O objeto event chega automaticamente como argumento.
};

2. Onde o event Está no Seu Widget

No seu registrationWidget, ele aparece em dois pontos principais.

Evento de clique no link "Voltar ao login"

document.getElementById("back-login-link").onclick = (event) => {
    event.preventDefault();
    onBackToLogin();
};

Aqui o evento é do tipo click. O navegador cria o objeto event quando o usuário clica no link.

Evento de envio do formulário

form.onsubmit = async (event) => {
    event.preventDefault();

    const username = usernameInput.value.trim();
    const email = emailInput.value.trim();
    const password = passwordInput.value;

    // ...
};

Aqui o evento é do tipo submit. Sem event.preventDefault(), o navegador tentaria enviar o formulário do jeito tradicional e recarregaria a página.

3. Tabela Rápida das Partes Mais Usadas

Uso O que significa Quando usar
event.preventDefault() Cancela o comportamento padrão do navegador. Formulário sem recarregar a página, link que não deve navegar, botão customizado.
event.target Elemento exato que disparou o evento. Descobrir se o clique foi no botão, no ícone dentro do botão ou em outro elemento filho.
event.currentTarget Elemento onde o listener foi registrado. Quando você quer o elemento "dono" do evento, não necessariamente o filho clicado.
event.type Nome do evento, como click, submit, keydown. Debug ou função compartilhada por vários tipos de evento.
event.stopPropagation() Impede que o evento suba para elementos pais. Botão dentro de card clicável, modal dentro de overlay, menu dentro de navbar.
event.key Tecla pressionada. Atalhos, detectar Enter, Escape, setas, etc.
event.clientX / event.clientY Posição do mouse na janela do navegador. Menus contextuais, drag and drop, tooltips, desenho em canvas.

4. preventDefault()

Alguns elementos HTML têm comportamento padrão. Um <form> tenta enviar dados. Um <a href="#"> tenta navegar. O preventDefault() cancela esse comportamento.

Formulário sem recarregar página

form.onsubmit = (event) => {
    event.preventDefault();
    console.log("Enviar via fetch/API");
};

Link usado como ação

link.onclick = (event) => {
    event.preventDefault();
    abrirTelaDeCadastro();
};
Se você esquecer preventDefault() no submit, a página pode recarregar e apagar o estado da interface.

5. target vs currentTarget

Essa é uma das partes mais importantes. target é quem foi clicado de verdade. currentTarget é onde você colocou o listener.

Se o usuário clica no ícone dentro do botão, target pode ser o ícone. Mas currentTarget continua sendo o botão, caso o listener esteja no botão. 

button.onclick = (event) => {
    console.log(event.target);        // elemento exato clicado
    console.log(event.currentTarget); // elemento que recebeu o onclick
};
Regra prática: use currentTarget quando você quer trabalhar com o elemento que recebeu o evento. Use target quando você precisa saber exatamente onde o usuário clicou.

6. stopPropagation()

Eventos sobem pela árvore HTML. Se você clica em um botão dentro de um card, o clique acontece no botão, depois pode chegar no card, depois no container, depois no documento. 

card.onclick = () => {
    abrirDetalhesDoCard();
};

deleteButton.onclick = (event) => {
    event.stopPropagation();
    excluirItem();
};

Sem stopPropagation(), clicar em "Excluir" poderia também abrir os detalhes do card.

7. type, key, clientX e clientY

event.type

Mostra o tipo do evento.

function logEvent(event) {
    console.log(event.type);
}

button.onclick = logEvent;  // "click"
form.onsubmit = logEvent;  // "submit"

event.key

Útil para teclado.

input.onkeydown = (event) => {
    if (event.key === "Enter") {
        console.log("Enter pressionado");
    }

    if (event.key === "Escape") {
        fecharModal();
    }
};

clientX e clientY

Posição do mouse dentro da janela.

document.onclick = (event) => {
    console.log("X:", event.clientX);
    console.log("Y:", event.clientY);
};

Exemplo: menu contextual

button.onclick = (event) => {
    menu.style.left = `${event.clientX}px`;
    menu.style.top = `${event.clientY}px`;
    menu.classList.remove("hidden");
};

8. Como Ler Sentenças com Ponto

Quando você vê objeto.algumaCoisa, leia como: "pegue algumaCoisa dentro de objeto".

Sentença Como ler
event.preventDefault() Chame a função preventDefault que existe dentro do objeto event.
alert.classList.remove("hidden") Pegue o elemento alert, acesse sua lista de classes e remova a classe hidden.
options.onRegistrationSuccess Pegue a função onRegistrationSuccess que foi passada dentro do objeto options.
response.status Pegue a propriedade status dentro do objeto response.

9. Debug: Como Ver o event Inteiro

Para aprender, coloque logs temporários dentro do evento. O console do navegador mostra o objeto completo. 

form.onsubmit = async (event) => {
    event.preventDefault();

    console.log("Evento completo:", event);
    console.log("Tipo:", event.type);
    console.log("Target:", event.target);
    console.log("Current target:", event.currentTarget);

    // resto do código...
};
Esses logs são bons para estudo, mas normalmente devem ser removidos ou reduzidos antes de deixar o código final.

10. Exercícios Rápidos

  1. Coloque console.log(event.type) no onsubmit do cadastro e veja o valor no console.
  2. Coloque console.log(event.target) no clique do link "Voltar ao login".
  3. Crie um botão com um ícone dentro e compare target com currentTarget.
  4. Remova temporariamente preventDefault() do formulário e observe o comportamento. Depois coloque de volta.
  5. Crie um card clicável com botão interno e use stopPropagation() no botão.
