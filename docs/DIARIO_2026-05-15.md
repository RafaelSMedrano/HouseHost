## Separacao do Frontend Estatico

Antes, os arquivos HTML, CSS e JavaScript ficavam em:



Confirmamos que o JAR novo nao inclui mais `index.html`, CSS ou JS. O JAR ficou como backend puro.

## Problema de Memoria na EC2

A instancia EC2 tem pouca memoria:

```text
~908 MiB RAM
0 swap inicialmente
```

Quando tentamos rodar:

```text
Spring Boot
MySQL
Nginx
Sistema operacional
```

o MySQL foi morto pelo Linux com:

```text
oom-kill
```

Isso significa que a instancia ficou sem memoria e o kernel matou o processo do MySQL.

Para corrigir, criamos swap:

```text
2 GB
```

Tambem reduzimos o consumo do MySQL com configuracao de baixa memoria:

```text
innodb_buffer_pool_size=128M
max_connections=30
performance_schema=OFF
```

Depois disso, MySQL e Spring Boot conseguiram rodar juntos.
