## My Projects

**[EduHub](https://github.com/RafaelSMedrano/EduHub)** - Educational social network built with PHP, Yii2, HumHub, MySQL and AWS. The project included web and Android access, user profiles, posts, comments, spaces, notifications and responsive customization for multiple devices.

**[Lumina](https://github.com/RafaelSMedrano/Lumina)** - Fullstack Java/Spring Boot project focused on real-time client-server communication with WebSocket, REST endpoints, MySQL persistence, user registration/authentication and a static JavaScript frontend.

**[LuminaJavaPuro](https://github.com/RafaelSMedrano/LuminaJavaPuro)** - Educational backend project built in pure Java to deepen understanding of what frameworks usually abstract. It implements real-time WebSocket communication, JSON-based protocols, layered architecture with handlers, services and DAOs, JDBC persistence and MySQL integration.
